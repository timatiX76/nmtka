nmtka — офлайн-тренажёр подготовки к ЗНО/НМТ
=============================================

Приложению нужен датасет: папка data/ с заданиями, изображениями и формулами.
Он лежит в самом репозитории.

Установка:
1. Скачай архив репозитория: зелёная кнопка «Code» на странице
   https://github.com/timatiX76/nmtka → «Download ZIP» (или
   git clone https://github.com/timatiX76/nmtka.git) и распакуй.
2. Скопируй nmtka.exe из этого архива в распакованную папку репозитория —
   рядом с папкой data/ (например: nmtka-main\nmtka.exe).
3. Запусти nmtka.exe двойным кликом. Приложение само найдёт data/.

Windows SmartScreen при первом запуске может показать предупреждение —
файл не имеет цифровой подписи. Нажми «Подробнее» → «Выполнить в любом случае».

Требования: Windows 10/11 x64, DirectX 11 или Vulkan.
Работает полностью офлайн.
