# Источники данных и лицензии

## Происхождение данных

Датасет собран с публичных страниц [zno.osvita.ua](https://zno.osvita.ua) (проект «Освіта.ua»).

| Что | Статус |
|---|---|
| Задания, варианты ответов, правильные ответы (`correct`, `correct_raw`) | официальные материалы УЦОЯО, публикуются государством |
| Метаданные: предмет, год, тип, порядок, ID, темы | фактические данные |
| Изображения, входящие в задание (`question_html`, `answers`, `groups`, `answer_table_html`) | часть официального задания |
| Разборы (`explanation_html`, `explanation_text`) и изображения `dc-*` | авторский контент «Освіта.ua», права принадлежат проекту «Освіта.ua» |
| Оформление, вёрстка, логотипы сайта | охраняемое оформление и брендинг «Освіта.ua» |

При использовании данных указывайте источник: «Задания — УЦОЯО, собрано с
zno.osvita.ua». Не выдавайте материалы за собственные.

## Сборка датасета без разборов

[tools/sanitize.py](../tools/sanitize.py) читает `data/` и пишет копию в `public/`
(или каталог `--out`): удаляет `explanation_html`/`explanation_text` и оставляет
только изображения, на которые ссылаются официальные части задания. Состав сборки
фиксируется в `MANIFEST.json`.

```powershell
python tools/sanitize.py
python tools/sanitize.py --subjects mathematics,ukrmova
python tools/sanitize.py --copy-images
```

## Проверка целостности

После пересборки датасета проверьте, что в копии нет разборов и что счётчики
заданий в `MANIFEST.json` сходятся с содержимым файлов.
