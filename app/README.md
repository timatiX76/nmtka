# Приложение

Нативное десктопное приложение на Rust (`eframe`/`egui`). Работает офлайн, читает датасет из корня репозитория.

## Запуск

```powershell
cd app
cargo run --release
```

Путь к датасету:

```powershell
cargo run --release -- "D:\nmtka"
$env:ZNO_DATA = "D:\nmtka"; cargo run --release
```

Если путь не задан, программа ищет `data/index.json` в текущей и родительских папках.

## Возможности

- Список 13 предметов со статистикой (тесты, задания, темы, варианты НМТ)
- Внутри предмета: варианты НМТ, демо-варианты, тесты по годам, задания по темам
- Прохождение теста: задание, варианты ответа, проверка, правильный ответ
- Типы заданий: `single_choice` и `multi_choice` (проверяются), `short_answer`
  (сравнение с учётом `,`/`.`), `matching`/`sequence` (самопроверка по эталону)
- Свой рендер HTML датасета: абзацы, **жирный**, *курсив*, подчёркивание,
  sup/sub, таблицы, списки, картинки (через `egui_extras`), `<latex>`
- Формулы — предрендеренные SVG из `assets/latex`
- Счётчик «верно N из M» за текущий тест

## Структура

```
app/
├─ Cargo.toml                 workspace
├─ assets/latex/              предрендеренные формулы (SVG)
├─ tools/latex/               скрипт предрендера (Node + MathJax)
└─ crates/
   ├─ zno-core/               serde-модели + доступ к датасету
   └─ zno-gui/
      ├─ src/main.rs          экраны и проверка ответов
      └─ src/html.rs          HTML → блоки egui
```

## Предрендер формул

```powershell
cd tools/latex
npm install
node render.mjs
```

Скрипт перебирает `<latex>…</latex>` в датасете и пишет по одному SVG на уникальную
формулу в `assets/latex/<sha1>.svg`, плюс `manifest.json` и `errors.json`.

## Планы

- Полный вариант НМТ с таймером
- Прогресс и статистика по темам (SQLite)
- Поиск по банку заданий (FTS5)
- Режим «работа над ошибками»
