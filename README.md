# nmtka

Офлайн-тренажёр подготовки к ЗНО/НМТ: нативное десктопное приложение на Rust и датасет заданий с ответами.

Всё работает без интернета: банк заданий, варианты НМТ, изображения и предрендеренные формулы лежат прямо в репозитории.

## Готовая сборка для Windows

1. Скачай архив репозитория: кнопка **Code** → **Download ZIP** (или `git clone`) и распакуй.
2. Скачай `nmtka-windows-x64.zip` со страницы [релизов](https://github.com/timatiX76/nmtka/releases/latest) и скопируй `nmtka.exe` в распакованную папку — рядом с папкой `data/`.
3. Запусти `nmtka.exe`. Подробности — в `docs/START-HERE.txt`.

Windows SmartScreen может предупредить о неподписанном файле: **Подробнее → Выполнить в любом случае**.

## Структура

```
nmtka/
├─ app/               приложение на Rust
│  ├─ crates/         zno-core (модели + датасет), zno-gui (интерфейс)
│  ├─ assets/latex/   предрендер формул в SVG (~10k)
│  └─ tools/latex/    скрипт предрендера формул (Node + MathJax)
├─ data/              датасет: задания, тесты, темы, варианты НМТ
├─ images/            изображения заданий
├─ preview/           HTML-просмотр датасета (открой index.html)
├─ tools/             sanitize.py — сборка копии датасета без разборов
└─ docs/              схема данных и заметка об источниках
```

## Приложение

```powershell
cd app
cargo run --release
```

Путь к датасету определяется так: аргумент командной строки → переменная окружения `ZNO_DATA` → авто-поиск `data/index.json` в родительских папках.

```powershell
cargo run --release -- "D:\nmtka"
$env:ZNO_DATA = "D:\nmtka"; cargo run --release
```

## Возможности

- 13 предметов со статистикой: тесты, задания, темы, варианты
- Тренировочные варианты НМТ, пробные (демо) варианты, тесты по годам, задания по темам
- Случайная десятка заданий из банка предмета
- Типы заданий: один вариант, мультивыбор, короткий ответ (сравнение с учётом `,`/`.`), соответствие и последовательность (самопроверка по эталону)
- Свой рендер HTML датасета: таблицы, списки, картинки, sup/sub, `<latex>`
- Формулы — готовые SVG из `app/assets/latex` (MathJax)
- Счётчик «верно N из M» внутри теста

## Данные

- `data/questions/<subject>.jsonl` — все задания предмета, по одному JSON на строку
- `data/tests/<subject>/` — тесты по годам и сессиям
- `data/nmt/<subject>/` — тренировочные варианты НМТ
- `data/topics/`, `data/tags/` — темы предметов и задания по темам
- Поля JSON описаны в [docs/schema.md](docs/schema.md)

Пересборка датасета из источников описана в [docs/LICENSING.md](docs/LICENSING.md).

## Источники

Задания и ответы — официальные материалы УЦОЯО, собраны с публичных страниц [zno.osvita.ua](https://zno.osvita.ua) (проект «Освіта.ua»). Разборы заданий принадлежат «Освіта.ua» — [tools/sanitize.py](tools/sanitize.py) собирает копию датасета без них. Подробности: [docs/LICENSING.md](docs/LICENSING.md).
